# TPE Parking

雙北停車場查詢與停車計費追蹤。

**👉 [開啟 App](https://twisttw77.github.io/tpe-parking/)**

手機打開後可以「加入主畫面」，就會像一般 App 一樣有圖示、全螢幕開啟，
也能在沒有網路的地下停車場使用。

---

## 功能

- **查詢**：雙北 3,054 個停車場，可依名稱、地址、營運公司搜尋，或依目前位置排序
- **計時**：按下開始停車後即時計時，並依該停車場的費率估算費用
- **費率**：支援首小時另計、每半小時進位、每日上限、平假日差異、時段差異（白天晚上不同價）
- **優惠折抵**：可記錄信用卡或消費優惠，勾選後自動扣抵時數重算費用
- **紀錄**：保存歷史停車紀錄與每月統計，支援補登與匯出備份
- **自訂**：任何停車場的資料與費率都能自行修正，修改後永久記住

## 資料來源

| 來源 | 筆數 | 授權 |
|---|---:|---|
| [臺北市停車管理工程處](https://data.taipei/) | 1,718 | 政府資料開放授權條款第 1 版 |
| [新北市資料開放平臺](https://data.ntpc.gov.tw/) — 新北市路外公共停車場資訊 | 1,336 | 政府資料開放授權條款第 1 版 |

僅收錄有汽車停車位的停車場。

## 費率準確度

費率是從開放資料的中文說明自動翻譯而來，準確度分三級並顯示在畫面上：

| 標示 | 筆數 | 意思 |
|---|---:|---|
| 費率明確 | 1,231 | 官方寫明計費與進位方式 |
| 進位為推估 | 1,122 | 金額明確，但未寫明不滿一小時如何計算，採較保守（估高）的算法 |
| 費率待確認 | 295 | 有分區、按次計費等變化，自動估算可能不準 |
| 需手動設定 | 404 | 其中 306 筆只有月租、不提供計時停車 |

**所有金額僅供參考，實際收費以現場為準。**

## 隱私

停車紀錄、收藏、自訂費率、個人備註全部只存在使用者自己的瀏覽器中，
不會上傳到任何伺服器。也因此換裝置或清除瀏覽器資料會消失，建議定期使用匯出備份。

## 開發

```bash
# 預覽
node tools/serve.js

# 更新停車場資料（重新下載並重建）
node tools/fetch-raw.js
node tools/build-data.js

# 測試
node tools/test-fares.js   # 費率翻譯
node tools/test-fee.js     # 費用計算
node tools/test-coords.js  # 座標換算
```

新增其他縣市：在 `tools/sources/` 增加一個轉換程式，
再於 `tools/build-data.js` 引用即可，不需更動 App 本身。
